## GitHub 업로드
1. ZIP 압축 해제
2. 안의 HTML 5개 파일을 모두 GitHub 저장소 최상위에 업로드 (동일한 이름은 덮어쓰기)
3. Commit changes
4. Actions에서 Pages 배포 완료 확인 후 웹사이트 강력 새로고침 (Ctrl + Shift + R)
5. 예전 gallery.html은 이제 메뉴에서 연결되지 않습니다. 원한다면 GitHub 저장소에서 삭제해도 됩니다.

HTML 파일은 스타일/스크립트/필요한 이미지를 파일 내부에 포함한 독립형 파일입니다.
